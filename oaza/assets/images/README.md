# OAZA image library

Put project photography here and reference it from `oaza/data/projects.js` or individual project content.

Suggested structure:
- `oaza/assets/images/oaza/` — general OAZA photography
- `oaza/assets/images/stadion/` — Stadion Starej Gwardii / SPOT #01
- `oaza/assets/images/beboki/` — Beboki
- `oaza/assets/images/hypeat/` — Hypeat

Example path from the site: `/oaza/assets/images/stadion/hero.jpg`

The site is intentionally structured around real image slots rather than embedding everything into one HTML file. New galleries can be added without rewriting the page layout.
