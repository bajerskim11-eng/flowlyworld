# CHILLERA

Pierwsza wersja strony CHILLERA w `flowlyworld/chillera/`.

## Kierunek

CHILLERA jest cyfrowo-fizycznym światem wokół chillu: OBJECTS, CHILL SPOTS, muzyka, kolekcje, mapa i późniejsza warstwa AR.

## V1

- landing page w jednym pliku HTML;
- ciemny industrialny design z acid-green akcentem;
- animowany Leaf Spinner jako główny artefakt;
- sekcje IDEA / OBJECTS / SPOTS / DOŁĄCZ;
- responsywność mobile;
- mikrointerakcje i reveal on scroll;
- koncepcja pierwszych kolekcji: KATO, JOKER, BEBOK, SILESIA, 420 KALEIDOSCOPE.
